Initial production release of [Virtualmin Podman](/docs/plugins/podman/) for Virtualmin Pro.

* Add links to the File Manager for files and directories mentioned in recipe instructions, with clearer path and domain formatting
* Add another 20 application recipes to the curated catalog: Adminer, Apache Tomcat, BookOrbit, Django, Draw\.io, FastAPI, Flask, FrankenPHP, Go, Grafana OpenTelemetry LGTM, Homer, InfluxDB, Mailpit, Node-RED, Node.js, Prometheus, RabbitMQ, Redmine, Ruby, SFTPGo
* Fix the recipe installation page with descriptions, option guidance, provider-linked images, and clearer application and dependency grouping
* Update Trilium Notes to its maintained image and current stable release
