* Add an optional managed scheduler so WordPress and ClassicPress tasks run without site visits
* Fix permission checks for site lists, remote servers, menus, and bulk actions
* Fix missing or outdated site information after refreshes
* Fix remote site links and actions after editing tags
* Fix backup schedules missing from the list and backups selecting the wrong site
* Fix login protection settings left behind when deleting sites
* Fix access errors after enabling password protection from the command line
* Fix site selection in command-line and API actions
* Fix bulk actions and tag editing for servers using IPv6 addresses
* Fix disabled settings appearing enabled on remote sites
* Fix disk usage labels when size collection is turned off
