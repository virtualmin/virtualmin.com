* Add scheduled image update checks, manual updates and version selection in the UI, CLI and remote API
* Add an option to control each domain owner's access to container apps
* Fix failed container updates to restore the original container and settings
* Fix ignored image-pull settings when creating or updating containers
* Fix unnecessary restarts and failures to find existing containers during updates
* Fix containers stopping when the root user logs out
