author: "Ilia Ross"
---

* Add Moodle, Joomla, Friendica, LimeSurvey, ClassicPress, DokuWiki, Grav and Piwigo application recipes
* Add RustDesk Server with direct network service support
* Add support for hiding terminal actions for application recipes without an interactive shell
* Fix stopped-pod port reservations and direct-service connection addresses
* Fix restart policy updates and automatic container and pod startup after reboot while preserving selected policies
* Fix overly long generated application login passwords
* Fix to show application recipe rollback results in a separate warning after deployment failures
