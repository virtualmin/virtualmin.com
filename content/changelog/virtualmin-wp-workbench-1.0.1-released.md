Initial production release of [WP Workbench](/docs/plugins/wp-workbench/) for Virtualmin Pro.

* System configuration management for PHP memory limits
* WordPress core settings management interface
* Comprehensive backup and restore functionality
* Site cloning to same domain, subdomain, or new domain
* Development tools including debug mode and maintenance mode
* Command line interface via `virtualmin configure-script --script-type wordpress`
* One-click WordPress admin access
* Fail2Ban integration for login protection
* Auto-update controls for WordPress core, plugins, and themes
* Permalink structure configuration
* Search engine visibility controls
* Comment settings management
* Add a dashboard notification message to inform users about the plugin
* Fix to clean environment correctly when cloning a site
* Fix saving debug modes correctly
* Fix the message when no action is selected to apply to the backups
